# A to F Fixers

Create a 5 page website for A to F Fixers, with the first image being the logo and the video being used on the hero section, then use the rest of the media for display and add them under projects. Use a mix on cool font like bold and sometimes italics, use a theme of a white background with light blue and black words to match the logo. Use a public storage bucket for all media. Ensure vite.config.ts explicitly includes an initialized plugins array (plugins: [...]) in defineConfig so Cloudflare deployment tools can successfully modify it.
